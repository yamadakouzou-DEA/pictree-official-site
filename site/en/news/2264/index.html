About PicTrée’s New Features (1.6.0)

PicTrée will undergo an update (v1.6.0) on Friday, February 21, 2025.
Here, we will explain the details of this update.

 

【Update Details】
① Reporting Function
② Asset Identifier Display Function
③ Limited Goods Exchange
④ NEBAARUKUN Collaboration
⑤ Investigator ID Update
⑥ AI-Based Image Review (Test Implementation)

 

① Reporting Function
If there is any issue with the photography target, you can now report it directly from the Pictorée app.
By tapping the megaphone icon in the top right corner of the utility pole information screen, you can select the item to report and also take a photo of the issue for submission.

 

② Asset Identifier Display Function
The “identifier” of the target utility pole will now be displayed below the asset name on the utility pole information screen.
The identifier starts with the company name, followed by a combination of letters and numbers.
This feature helps distinguish which utility pole is the target when multiple poles are in close proximity.
Please note that there are various patterns for identifiers, and they may not always perfectly match the display in PicTrée. Consider them as reference information.

 

③ Limited Merchandise Exchange Feature
The “Limited Merchandise Exchange,” which previously required an external form application, will now be available directly within the PicTrée app.
Please check the images below for detailed instructions on how to exchange merchandise.


 

 

④ NEBAARUKUN Collaboration
In the North Kanto Season, a special collaboration with the unofficial character NEBAARUKUN will take place.
The collaboration details are as follows:
 – Appearing as the Support Character for “Team Ibaraki”: NEBAARUKUN will be featured as the official team illustration and icon for Team Ibaraki in the North Kanto Season.
 – Special Collaboration Items: NEBAARUKUN-themed items will be available in treasure chests and for purchase in the in-game shop.
 – Special Utility Poles: Exclusive NEBAARUKUN collaboration utility poles will appear in the game.
 – Special Effects: A unique NEBAARUKUN animation will be displayed when connecting utility poles.


 

 

⑤ Investigator ID Update
The content of the Citizen Investigator ID, which can be displayed in the PicTrée app, has been updated.
Users can now select an investigator ID for each season, so please make use of it according to the season you are participating in.

 

⑥ AI-based Image Check (Test Implementation)
A trial AI-powered image check function will be introduced.
The AI will assess whether the captured image matches the intended subject and will request a retake if the image does not meet the criteria.
During this test phase, the AI’s judgment may be unstable, which could result in retake requests even when the photo is correctly taken. If this happens, please report the issue using the Report Function.
