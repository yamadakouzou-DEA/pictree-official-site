地際プロピクター撮影マニュアル

招待制 特別シーズン

地際プロピクター
撮影マニュアル

このシーズンでは、電柱と支線の「地際（じぎわ）」を撮影します。点検担当者が写真だけで錆や腐食を判断できるよう、通常シーズンより厳密な撮り方が決まっています。撮影前に一度目を通してください。

地面と電柱・支線の境目が見えていない写真はNGになります。

地際とは　電柱や支線（電柱を斜めに支えるワイヤー）が地面と接している根元のこと。雨水や土で錆びやすく、点検で最も重視される部分です。

なぜプロピクターの写真が必要なのか

地際は草などに隠れやすく、写真で確認できないことがあります。しかし、錆が最も発生しやすい場所でもあります。皆さんの写真で地際の状態が分かれば、電柱の状態を正しく判断できます。

錆を見つけるには、露出させた地面と電柱・支線の境目が写っていることが欠かせません。草や落ち葉、小石を取り除き、地面を露出させてから撮影してください。

根元に寄って3方向から撮る、ピクトレの中でも特に難しい撮影です。だからこそ、質の高い写真を撮影できるプロピクターの皆さんにお願いしています。

あなたの写真が、まちの電柱を守ります。

撮影より安全が優先です

撮影前に周囲の交通状況を確認し、安全が確保できる状態で撮影してください。車道側に回り込むなど危険があると判断したときは、無理をせず安全な位置から撮影してください。私有地には立ち入らないでください。

持ち物：軍手（推奨）

地際の草・枯れ草・落ち葉・小石を取り除くときに使います。素手で触るとけがをするおそれがあるので、軍手の持参をおすすめします。

STEP 2 ・ 鋼管柱

鋼管柱の地際
（本柱・支柱共通）

金属製の電柱（鋼管柱）の根元を、近づいて3方向から撮影します。本柱・支柱のどちらも、この撮り方で撮影してください。支柱が斜めに立っている場合は、横からの画角（地際②③）で支柱が斜めに写ります。

必須

草などを取り除き、
露出させた地面と
電柱の境目を見せる

点検担当者は、露出させた地面と電柱の境目に錆がないかを見ています。この部分がはっきり見える状態で撮影してください。

  • 草などがあり、地面と電柱の境目が見えていない
  • 枯れ草・落ち葉の層があり、地面と電柱の境目が見えていない
  • 小石などがあり、地面と電柱の境目が見えていない

草・枯れ草・落ち葉がある場合、周りを踏み固めていても、地面と電柱の境目が見えていなければNGです。

地面と電柱の境目が見えるまで除去してから撮影する（軍手を着用）

地際 ×3

根元に寄って3方向

距離 30〜50cm方向 3
  • 露出させた地面と電柱の境目が見えるように撮影する。草・枯れ草・落ち葉・小石で見えないときは、見えるまで除去してから撮影する
  • 周囲の道路状況などに応じて、異なる3方向から撮影する。撮影方向は自由です。安全を優先して撮影してください
  • 被写体までの距離は約30〜50cm。電柱の左右の両端が画面に入る距離にする
  • 地面と接している部分にピントを合わせる。逆光・ピンボケに注意
  • 根元に錆が見えるときは、錆がはっきり写るように撮影する

STEP 3 ・ 支線

支線の地際

電柱を斜めに支えるワイヤー（支線）が地面に入る部分を、3方向から撮影します。鋼管柱より少し近い距離です。

必須

草などを取り除き、
露出させた地面と
支線の境目を見せる

点検担当者は、露出させた地面と支線の境目に錆がないかを見ています。この部分がはっきり見える状態で撮影してください。

  • 草などがあり、地面と支線の境目が見えていない
  • 枯れ草・落ち葉の層があり、地面と支線の境目が見えていない
  • 小石などがあり、地面と支線の境目が見えていない

草・枯れ草・落ち葉がある場合、周りを踏み固めていても、地面と支線の境目が見えていなければNGです。

地面と支線の境目が見えるまで除去してから撮影する（軍手を着用）

地際 ×3

地面に入る部分に寄って3方向

距離 約30cm方向 3

  • 周囲の道路状況などに応じて、異なる3方向から撮影する。撮影方向は自由です。安全を優先して撮影してください
  • 被写体までの距離は約30cm
  • 逆光・ピンボケがないこと
  • 地際に錆が見えるときは、錆がはっきり写るように撮影する
支線カバー

カバーが地際を覆っている場合

支線カバーを上にあげて撮影

  • 支線カバーが地際部分を覆っている場合は、カバーを上にずらし、支線が地面に入る部分を露出させてから撮影する
  • 撮影後は、支線カバーを元の位置に戻す
安全上の注意
